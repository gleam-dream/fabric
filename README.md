# fabric

A partial Gleam port of BeamWeaver: a typed DAG compiler, durable OTP execution, an autonomous LLM agent loop, and provider wire adapters, with a runtime action-authorization seam.

Status: design-stage; see [fabric-design.md](https://github.com/gleam-dream/oversight/blob/master/fabric-design.md) in [gleam-dream/oversight](https://github.com/gleam-dream/oversight). Not yet published to Hex.

Ports/wraps: BeamWeaver.

## Development

```sh
nix develop
gleam test
```
